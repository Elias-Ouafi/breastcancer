# What the demo needs, and nothing else.
#
#   pip install -r requirements-demo.txt
#   python run_demo.py
#
# Why a second file rather than `requirements.txt`: the full install resolves 68
# packages / 355 MB on Windows and 67 / 1,01 GB on Linux x86_64 (mesuré le
# 2026-09-20, `pip install --dry-run --report` + HEAD sur chaque roue). The demo
# path imports four of them -- torch, Flask, numpy, Pillow -- and reaches nothing
# else: `run_demo.py` -> `app.server` -> `app.predictor` -> `inference` ->
# `imaging.unet`. The rest (tcia-utils, pandas, matplotlib, duckdb, python-gdcm,
# pyarrow...) belongs to the collection and catalogue paths, which a demo never
# walks. This list resolves 17 packages / 153 MB on Windows, 0,80 GB on Linux.
#
# It deliberately does NOT install the project itself: the demo is run from the
# clone (`python run_demo.py` at the root), which is how the Docker image runs it
# too. Use `requirements.txt` for everything beyond the demo.
#
# torch: installs the default wheel for your platform. On Linux that wheel carries
# CUDA. For a CPU-only box, install it first from the matching index:
#   pip install torch --index-url https://download.pytorch.org/whl/cpu
torch>=2.2
Flask>=3.0
numpy>=1.26,<2
Pillow>=10.2,<11
